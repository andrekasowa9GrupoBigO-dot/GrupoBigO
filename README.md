Este projeto implementa um sistema de logística de encomendas a nível nacional, modelado através de grafos ponderados, onde os vértices representam províncias de Angola e as arestas representam rotas rodoviárias com pesos reais (distâncias).

O sistema utiliza o Algoritmo de Dijkstra para determinar a rota de menor custo entre uma província de origem e uma de destino, garantindo eficiência na busca do caminho mais curto. A estrutura do grafo é totalmente conectada de acordo com o mapa nacional, permitindo simular cenários reais de transporte.

A aplicação foi desenvolvida em Java, com uso de Programação Orientada a Objetos, estruturas de dados eficientes (HashMap, List) e uma interface gráfica em Swing para visualização das províncias, regiões e rotas calculadas.

O projeto tem fins académicos, servindo como aplicação prática de conceitos de Algoritmos e Estruturas de Dados, especialmente grafos e otimização de caminhos.

//Tecnologias Utilizadas
Java
Swing (visualização gráfica)
Estruturas de Dados (HashMap, List, Set)
Algoritmos em Grafos (Dijkstra)

//Objetivos do Projeto
Modelar o sistema logístico nacional de Angola usando grafos
Calcular a rota mais curta entre províncias
Aplicar conceitos de estruturas de dados e algoritmos
Desenvolver uma solução eficiente e organizada para fins académicos
